# Burger Kitchen Bangladesh — Enhanced Static Website

A polished multi-page static restaurant website focused on burgers with chicken, pizza, wraps, sides, shakes, beverages, desserts and breakfast.

## Included
- 13 standalone HTML pages with separate navigation destinations
- Transparent-background Burger Kitchen logo
- Responsive desktop/tablet/mobile layout
- Scroll-reveal and stagger animations
- Animated hero, ticker, cards, buttons and cart drawer
- Bangladeshi Taka (৳ / BDT) pricing
- Search and category filtering on the full menu
- Persistent demo cart using localStorage
- Mobile navigation
- Homepage expanded with fan favorites, reviews, FAQ and ordering guidance

## Run
Open `index.html` in a browser. No build step is required.

## Production note
The checkout button is intentionally a static demo. Connect it to your real ordering backend/payment gateway (bKash, Nagad, SSLCommerz, etc.) before accepting payments.
